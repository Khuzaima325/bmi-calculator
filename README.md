# BMI Calculator

A BMI calculator in plain HTML, CSS and JavaScript, with metric (kg/cm) and
imperial (lb/in) units and a color-coded category scale.

## Features

- Metric and imperial unit toggle
- BMI value plus category: underweight, normal, overweight, obese
- Visual category scale
- No dependencies, works offline

## How to run

Just open `index.html` in your browser.

## Honest note

BMI is a rough screening measure — it doesn't account for muscle mass, age or
health conditions. Talk to a clinician for personal advice.
